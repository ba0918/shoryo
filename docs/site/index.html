始める前に。

shoryo 自体が AI に返事を頼むのですか？

ブラウザはモデルの API を直接呼びません。スキルに従って動くエージェントが、CLI を通じて問いを出し、質問に返事を届けます。エージェント側の環境が必要です。

データはどこに残りますか？

議題のデータはリポジトリの外にあるユーザーごとのデータディレクトリに保存されます。Linux の既定は ~/.local/share/shoryo/ です。サーバーは既定で 127.0.0.1 だけで待ち受けます。

どんなエージェントで使えますか？

README には Claude Code の導入例があります。ほかのエージェント向けのスキル導入は、gh skill install --help で対応先とオプションを確認してください。スキルを読む ↗

以前のバージョンから使っている場合は？

v0.1.1 では説明データの形式が変わっています。旧形式の議題は新バイナリでは起動できません。以前のバイナリを残し、README の移行に関する注意を確認してください。
